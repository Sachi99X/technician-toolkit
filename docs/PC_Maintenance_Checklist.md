# PC Maintenance Checklist

Use this checklist as a routine reminder. Adapt frequency to the device, environment, and manufacturer's guidance.

## Physical condition
- [ ] Check for blocked vents and excessive dust.
- [ ] Confirm fans operate normally and listen for unusual noise.
- [ ] Inspect cables, ports, and peripherals for visible damage.
- [ ] Keep liquids away from equipment.
- [ ] Power down and unplug before external cleaning; use suitable electronics-safe methods.

## Software health
- [ ] Install operating-system updates from official sources.
- [ ] Update applications from trusted vendors.
- [ ] Review installed applications and remove only those you recognize and no longer need.
- [ ] Review startup applications.
- [ ] Run a trusted security scan.
- [ ] Check available storage space.
- [ ] Confirm date, time, and backup status.

## Data protection
- [ ] Verify important files are backed up.
- [ ] Periodically test that a backup can be restored.
- [ ] Keep recovery keys and passwords stored securely; never publish them in a repository.
- [ ] Avoid storing personal data, serial numbers, or private logs in public GitHub repositories.

## Hardware health
- [ ] Review system temperatures using trusted tools.
- [ ] Check drive health using manufacturer-recommended utilities.
- [ ] Note battery condition on laptops.
- [ ] Record recurring errors and their dates.
