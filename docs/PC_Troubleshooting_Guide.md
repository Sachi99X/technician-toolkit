# PC Troubleshooting Guide

A structured checklist for diagnosing common desktop and laptop issues.

## 1. Before you begin
- Ask what changed recently (updates, new hardware, spills, drops, power outage).
- Record the exact error message and when the issue occurs.
- Back up important data before risky repairs.
- Get permission before opening or changing someone else's device.
- Shut down and unplug equipment before handling internal components.
- Never open a power supply unit (PSU); it can retain dangerous voltage.

## 2. No power
1. Check the wall outlet and power cable with a known-good, safe alternative.
2. Check the laptop charger and charging indicators, if applicable.
3. For a desktop, check the PSU rear switch and power connection.
4. Disconnect unnecessary peripherals and try again.
5. If there is a burning smell, liquid damage, sparks, or unusual heat, stop and seek qualified service.

## 3. Powers on, but no display
1. Confirm the monitor is powered on and set to the correct input.
2. Check the display cable and try another known-good cable or display.
3. If a dedicated GPU is installed, verify the monitor is connected to the correct output.
4. Note motherboard debug LEDs or beep codes, using the board manual.
5. Reseat components only if you are trained to do so and the system is unplugged.

## 4. Slow performance
1. Check available storage space.
2. Review Task Manager or the operating system's process monitor.
3. Check startup applications and recently installed software.
4. Run trusted security scans and install updates from official sources.
5. Check temperatures and fan operation without touching moving parts.
6. Test storage health with the manufacturer's recommended diagnostic tools.

## 5. Network problems
1. Confirm Wi-Fi or Ethernet is enabled and airplane mode is off.
2. Check whether other devices can connect.
3. Restart the router only if you have permission and understand the impact.
4. Verify IP configuration and DNS settings.
5. Record command output and error messages before changing settings.

## 6. Windows will not boot
1. Record any stop code or error message.
2. Disconnect unnecessary external devices.
3. Use Windows Recovery Environment and built-in repair options.
4. Consider recent drivers, updates, or hardware changes.
5. Back up data before reset or reinstall options; these can cause data loss.

## 7. Linux boot or package issue
1. Record the distribution, version, and exact error.
2. Check disk space and system logs.
3. Use the distribution's official documentation.
4. Avoid copying commands from unknown sources, especially commands using `sudo`, `rm`, or disk tools.
5. Back up important data before partition or bootloader changes.
