# IT Technician Starter Portfolio

A practical starter portfolio for learning and documenting computer hardware, Windows, Linux, and IT support.

## Contents
- `docs/PC_Troubleshooting_Guide.md` — a safe, step-by-step troubleshooting workflow
- `docs/PC_Maintenance_Checklist.md` — preventive maintenance checklist
- `docs/Windows_Support_Notes.md` — useful Windows support commands
- `docs/Linux_Command_Cheatsheet.md` — beginner-friendly Linux commands
- `scripts/Windows_System_Inventory.ps1` — read-only Windows system inventory script

## Important
This repository is a learning portfolio template. Update it with your own notes, test results, and screenshots as you gain experience. Do not claim a skill or repair as professional experience unless it reflects work you have actually done.

## How to use
1. Upload this folder's contents to a new GitHub repository.
2. Read and customize each guide.
3. Test scripts only on systems you own or are authorized to manage.
4. Add examples from your own learning and troubleshooting practice.
